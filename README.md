# 🍔 My Food Delivery App

A modern, responsive food delivery web application built using **React** and **CSS**. 
This application allows users to browse food items, manage their cart, and place orders with a smooth and intuitive user experience.

<img width="1920" height="1080" alt="Screenshot (140)" src="https://github.com/user-attachments/assets/80e70a46-02d9-4a3b-b461-25214e82bb4c" />

## 🚀 Features
- Dynamic Home, Cart, and Place Order pages
- Add, remove, and update items in the cart
- Real-time order summary with price calculation
- Fully responsive design for desktop and mobile devices
- Clean and modern user interface
